# UBS Saúde & Cuidado

Protótipo funcional e responsivo de um site informativo para uma Unidade Básica de Saúde (UBS), desenvolvido para fins acadêmicos.

## Funcionalidades

- Horários de atendimento
- Serviços oferecidos
- Documentos necessários
- Informações sobre vacinação
- Orientações sobre consultas
- Contatos e localização
- Perguntas frequentes (FAQ)
- Área de saúde mental
  - Ansiedade
  - Depressão
  - Orientação sobre onde buscar atendimento
- Layout responsivo para celular, tablet e computador
- Menu mobile em JavaScript

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone o projeto.
2. Abra o arquivo `index.html` no navegador.
3. Edite os dados de endereço, telefone, horários e serviços conforme a UBS parceira.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e `README.md`.
3. No repositório, abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde a publicação.

## Observação

As informações institucionais presentes neste protótipo são exemplos. Antes da entrega final, substitua por dados oficiais da UBS parceira.
